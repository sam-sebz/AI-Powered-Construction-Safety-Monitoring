# PRD

## Goal
Provide a local engineering safety prototype that combines computer vision, safety rules, persistence and measurable evaluation.

## Users
Site safety supervisors, engineering technology teams and project controls teams.

## MVP
1. Upload worker image
2. Classify PPE compliance
3. Evaluate restricted-zone events
4. Record incidents
5. View model metrics and incident history

## Success criteria
- Reproducible training
- API workflow works locally
- Incidents persist
- Browser UI exposes the main workflow
- Evaluation metrics are documented

## Out of scope
Production CCTV deployment, cloud hosting, SSO and real employee data.
